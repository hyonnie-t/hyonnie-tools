시행일: 2026-11-05

다루는 정보

이 도구는 소유자 본인의 구글 계정에 있는 스프레드시트, 드라이브, Apps Script, 캘린더, 문서, 슬라이드, 설문 데이터만 소유자가 요청한 작업에 필요한 범위에서 읽고 고칩니다. 다른 사람의 계정으로는 로그인하지 않습니다.

사용과 전달

구글 사용자 데이터를 판매하거나 광고에 쓰지 않습니다. 소유자가 쓰는 AI 도우미(Anthropic의 Claude)가 도구를 실행하므로, 읽은 내용은 소유자의 요청을 처리하는 범위에서 그 도우미에 전달될 수 있습니다. 그 밖의 곳으로는 보내지 않습니다. 구글 API에서 받은 정보의 사용은 Limited Use 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

보관

로그인 토큰은 소유자의 PC에만 저장합니다. 이 도구는 별도의 서버나 데이터베이스를 두지 않습니다.

삭제와 권한 철회

소유자는 PC의 토큰 파일을 지우거나 구글 계정 권한 페이지에서 언제든 접근 권한을 철회할 수 있습니다.

Summary in English

This tool accesses only its owner's own Google data, as the owner requests. It does not sell Google user data or use it for advertising. An AI assistant used by the owner (Anthropic's Claude) runs the tool, so data it reads may be passed to that assistant to process the owner's requests, and nowhere else. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Sign-in tokens are stored only on the owner's computers, and access can be revoked at any time from the Google Account permissions page.
